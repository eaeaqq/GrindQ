# 笔试题练习记录

打开 `index.html` 即可使用。题库和做题记录保存在当前浏览器的本地存储里。

## 第一版功能

- 手动新增、编辑、删除题目
- 从文本批量导入选择题
- 从 Excel 题库导入选择题
- 导入后保留 AI 判断答案、参考答案、解析、来源文件和页码
- 按全部题目、错题、收藏练习
- 提交后记录正确率、错题次数和做题历史
- 提交后直接显示答案解析，包含 AI 判断答案和参考答案
- 导出/导入 JSON 备份

## 批量导入格式

```text
1. 题干
A. 选项一
B. 选项二
C. 选项三
D. 选项四
答案：B
解析：可选
```

## PDF 转 Excel

使用 `tools/pdf_to_excel.py` 可以把 PDF 题目抽成 app 可导入的 Excel。

```powershell
python .\tools\pdf_to_excel.py "..\八股\华为笔试题" -o ".\华为题库导入.xlsx" -b "华为数字芯片"
```

推荐 Excel 表头为：题库、题型、题干、A-H、AI判断答案、原文答案、解析、知识点、校准备注、来源文件、页码、重复来源。
